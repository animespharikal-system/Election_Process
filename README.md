https://votepath-app-6f912.web.app

## 📌 Overview

**VotePath** is an interactive web application that helps users understand the election process in a clear, simple, and structured way.

It is designed especially for:

* First-time voters
* Students
* Educators
* Civic awareness initiatives

The goal is to remove confusion around elections by breaking everything into **easy-to-follow steps and visuals**.

---

## 🚀 Features

* 🧭 **Interactive Election Process Guide**
  Step-by-step explanation of how elections work

* 📝 **Voter Registration Assistance**
  Guidance on how and where to register

* ✅ **Eligibility Checker**
  Helps users determine if they can vote

* 📅 **Election Timeline Visualization**
  Important dates and milestones clearly presented

* 🗳️ **Voting Methods Comparison**
  Explains different ways to vote

* 📖 **Election Glossary**
  Simplifies complex terms

* 🤖 **AI-Powered Chat Assistant**
  Provides quick answers and guidance

* 📱 **Responsive Design**
  Works across mobile, tablet, and desktop

* ♿ **Accessibility-Focused UI**
  Designed for ease of use by all users

## 🚀 Deployment

This project is deployed using **Firebase Hosting**.

To deploy:

```bash
npm install -g firebase-tools
firebase login
firebase init hosting
firebase deploy
```
