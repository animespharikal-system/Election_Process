# VotePath – Election Process Assistant

An interactive web application designed to help users understand the election process, timelines, voter registration, eligibility, voting methods, and important deadlines through an intuitive and user-friendly experience.

---

## Overview

VotePath simplifies the election process by providing clear, step-by-step guidance for voters. It is designed for first-time voters, students, educators, and civic organizations.

---

## Features

- Interactive election process guide
- Voter registration assistance
- Eligibility checker
- Election timeline visualization
- Voting methods comparison
- Election glossary
- AI-powered chat assistant
- Mobile-responsive design
- Accessibility-focused interface

---

## Technology Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Antigravity
